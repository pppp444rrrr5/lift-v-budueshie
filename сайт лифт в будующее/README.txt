СТРОЙРЕСУРС — МНОГОФАЙЛОВАЯ ДЕМО-ВЕРСИЯ

Откройте index.html в браузере. Все страницы находятся в одной папке:
index.html — обзор; procurement.html — закупки; warehouse.html — склад;
substitutes.html — импортозамещение; analytics.html — аналитика; bim.html — ТИМ/BIM.

css/style.css — общие стили.
js/app.js — функции существующего прототипа.
js/profile.js — окно профиля.
assets/ — папки для изображений и иконок.

Профиль и складские данные сохраняются в localStorage этого браузера.
Серверная авторизация, общая база пользователей и реальные интеграции не подключены.
Для внешних API предпочтительно запускать проект через локальный веб-сервер.
